How a show works

A show creates a Blinken object and passes an initializer function to its run() method. The initializer is called once with an array of the 100 lights, and returns a step function. The step function is called over and over to update the lights, and returns how many milliseconds to wait before the next step.

const b = new Blinken({title: "Red and Green", author: "Your Name"});

b.run((lights) => {
  let red = true;
  return (lights) => {
    for (const light of lights) {
      if (red) {
        light.rgb(1, 0, 0);
      } else {
        light.rgb(0, 1, 0);
      }
    }
    red = !red;
    return 500;  // milliseconds until the next step
  };
});

If the step function returns a negative number, the show ends.

Controlling the lights

Each light has red, green, and blue channels and a brightness (alpha), all from 0 to 1. You can set them directly (light.r = 0.5) or with these methods:

  • rgb(r, g, b) sets the color at full brightness, and rgba(r, g, b, a) sets the color and brightness.
  • red(), green(), blue(), cyan(), purple(), yellow(), white(), and black() set simple colors.
  • copy(otherLight) and add(otherLight) copy or add another light's color, and clear() resets a light to black.
  • new Bulb(r, g, b, a) makes a light you can keep and copy from.

Use console.log() to debug: its output appears in the playground's console.

Running on the stairs

Press Run on Stairs in the playground. Your show may wait in line behind others, and then runs for up to two minutes. When no one has a show queued, the stairs play shows from the gallery.

On the stairs, shows run in a sandbox with a few limits:

  • Starting the show may take up to 1 second, and each step up to 100 milliseconds.
  • Shows can only use the lights. There's no access to the network, timers, or a web page.
  • The real bulbs only have 16 levels for each color, and total power is limited, so the stairs may look a little different from the simulator.

Saving and sharing

The playground saves your shows in your browser as you type; open My shows to switch between them, start a new one, or upload a file. Saved shows stay in that browser only, so use Download to keep a copy. Share gives you a link to your code. Submit to Gallery sends your show for review; once approved, it appears in the gallery, where people can vote for it and remix it.

Older shows

Shows written for the old jsbin setup still work. Paste their JavaScript into the playground, or keep loading client.js in your own page.
